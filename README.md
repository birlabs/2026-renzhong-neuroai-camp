# 任重书院学术训练营年度计划（2026–2027）

## 智能从何而来：从大脑神经机制到具身智能

- **指导教师**　曾太平（类脑智能科学与技术研究院）
- **内容简介**　围绕“大脑如何产生智能”，研讨空间认知、学习记忆、神经表征、神经动力学和数字孪生脑。通过经典与前沿文献阅读、数据分析和计算建模，理解脑认知功能的神经计算机制，探索其对人工智能与具身智能的启发。
- **所涉及学科**　数学、物理学、神经科学、人工智能、计算机科学、认知科学、机器人学、生物医学工程、信息科学。
- **项目开展时间**　自开营起 12 个月，固定双周组会。具体时间开营后根据组员课表协商确定。
- **项目活动频率**　每月 2 次集中组会，全年计划 24 次。每月一次文献精读，一次专题讨论或实践指导，结合进展安排小组讨论和个别指导。
- **报名要求**　不限专业。对脑科学、具身智能或机器人有浓厚兴趣，具备基本英文文献阅读能力和主动学习能力。

## 二、年度安排

面向 8 名本科生。前期共学并认领个人专题，第 7 月组建 2–3 个跨专业实践小组。

| 时间 | 任务 | 交付 |
| --- | --- | --- |
| 第 1–2 月 | 基础共读，练习文献检索、论文三遍读法和 Python 读图。 | 1 张论文卡、1 份读图练习 |
| 第 3–4 月 | 认领细分方向，配对精读 1 篇经典论文与 1 篇近期论文。 | 共享文献库、论文汇报 |
| 第 5–7 月 | 依次研讨空间编码与导航、学习记忆与神经动力学、数字孪生脑与具身智能。 | 专题短综述、专题汇报、每组 1 页开题方案 |
| 第 8–10 月 | 跑通基线，完成对照实验，分析误差，由其他组复跑关键结果。 | 代码或 Notebook、结果图表、实验记录 |
| 第 11–12 月 | 报告互评、成果演示与学术汇报。 | 每组 1 篇研究报告或综述、1 次结营汇报 |

## 四、实践与结营

**共同练习**　用公开的海马神经记录绘制位置细胞的空间放电率曲线，解码动物位置，并在留出的跑次上计算平均绝对位置误差。 [MIT CBMM 数据与示例](https://cbmm.mit.edu/learning-hub/tools-datasets/decoding-hippocampal-place-cell-data)

**自主选题**　结合前期阅读和专题讨论，各组可从感兴趣的现象、方法或应用场景出发，也可跨方向组合。根据可用的数据、仿真环境或实验条件，自拟一个能够验证的研究问题。 [MiniGrid 仿真环境](https://minigrid.farama.org/v2.4.0/environments/minigrid/) · [LeRobot PushT 示范数据](https://huggingface.co/datasets/lerobot/pusht_image)
